# 速驱智控透明桌面图标处理说明

日期：2026年11月10日。用户要求“图标周边的白色背景有点丑，把边缘的白色去掉。再更新安装”。

## 来源及产物

- 编辑目标：工作区`图标/手机APP桌面图标2.png`。原图1254×1254、RGB，SHA256为`5781778ade4e71f4a435d57f08bad54585aa781408bdfbca414c8bf1153df3e8`，未覆盖原始文件。
- 编辑方式：内置imagegen工具，透明背景参数为true；没有使用CLI或自行编写抠图程序。用户圈注截图仅用于说明去除外围白底，正式编辑使用完整原图。
- 透明主图：[launcher-icon-transparent.png](./launcher-icon-transparent.png)，1254×1254、RGBA，SHA256为`6d6eda281182594aa34604f22e0d2acaea22c4cd4f246926db011c094afb3fe4`。
- 安卓资源：主图保留alpha，用Lanczos等比例导出72、96、144、192像素。由`AndroidManifest.xml`中既有的`@drawable/icon`引用。

## 最终编辑提示词

```text
用途：背景抠图，安卓应用桌面图标。编辑目标为附图这一张现有SQ图标。只去除蓝色圆角方形主体外侧、与画布边缘相连的白色背景，将其变为真正透明的alpha背景，包含四个圆角外侧的白色角落和极细白边。严格保留原图的蓝青渐变、圆角主体轮廓、光泽、SQ字母的形状位置、内部白色高光、底部Wi-Fi/蓝牙/信号三个符号和所有内部细节。不要把主体内部的白色或浅色部分变透明，不改变文字、不重画、不增加阴影、边框、标注、水印或其他背景。保持正方形构图和主体原有比例，主体尽量填满画布但不裁切。输出一张边缘干净、具有真实透明背景的PNG。
```

## 检查方法

目视检查透明主图及192像素导出图，确认SQ字母、内部白色高光和底部三个符号保留，外围白底消失。正式APK检查提取实际四种密度PNG，核对字节校验值、四角alpha为0以及中央四分之一至四分之三区域alpha至少250，防止主体被误抠空。生成主图中心alpha实际为253，因此检查主体保留而非要求每个主体像素必须等于255；旧白底图的四角为255，仍会被检查拒绝。
